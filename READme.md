ARCHIVE.
[View live site](https://archive-olaglobal.vercel.app)

Nigeria’s sound, told one album at a time.

A fictional digital museum exploring Nigeria’s musical history through ten selected albums, their artwork, and the stories behind the sound. Built for the DesignIndependently challenge.

Features
- Responsive desktop and mobile layouts
- Animated album-cover strip
- Collection filters by decade
- Album stories and listening links

Built with
HTML, CSS, and vanilla JavaScript.

Run locally
Open index.html with VS Code’s Live Server extension. Keep the img folder in the project directory.
